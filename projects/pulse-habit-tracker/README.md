# Pulse — Minimalist Habit & Streak Tracker

A lightweight, client-side habit and streak tracking web application built in vanilla HTML, CSS, and JavaScript.

## Features
- **Live SVG Daily Progress Ring**: Smooth animated completion ring dynamically synced with daily check-ins.
- **14-Day Interactive Activity Matrix**: Visual streak calculation, completion grid, and quick habit creation/deletion persisted in `localStorage`.
- **Canvas Confetti Celebration**: Lightweight HTML5 Canvas particle celebration on reaching 100% daily completion.

## Run Locally
Open [index.html](index.html) directly in any modern browser.
