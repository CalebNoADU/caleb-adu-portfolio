How Semantic Vector Search Works

Traditional search looks for exact character matches (Ctrl+F). The Python CLI engine (search_engine.py) converts each query into an L2-normalized 1,500-dimensional coordinate via IDF-weighted distributional co-occurrence embeddings, then scores 11,992 normalized passage vectors across 13 public-domain novels via cosine dot product. This static browser preview showcases real top-ranked retrieval snapshots without shipping the 167 MB binary index.
